# 출시 노트

Play Console 에 올라가는 "새로운 기능"(출시 노트) 원문. 버전 코드별 디렉터리
아래에 **로케일별 파일 하나**씩 둔다.

```
release-notes/16/ko-KR.txt
release-notes/16/en-US.txt
release-notes/16/ar.txt
...
```

파일 이름(확장자 제외)이 곧 Play 로케일 코드다.

## 규칙

- **스토어 등록정보에 있는 모든 로케일을 채운다.** 한 언어만 넣으면 나머지
  언어 사용자에게는 아무 설명 없이 업데이트가 나간다. 현재 등록정보에 어떤
  로케일이 있는지는 `play-status.yml` 을 돌리면 마지막에 출력된다.
- **등록정보에 없는 로케일은 넣지 않는다.** 하나라도 섞이면 Play API 가 업로드
  요청 전체를 거절한다.
- **로케일당 500자를 넘지 않는다.** Play 의 상한이다.
- 번역할 때 한국어 원문을 그대로 복사해 두지 않는다. 안 채운 것과 같다.

앱 UI 는 77개 언어를 지원하지만 출시 노트는 스토어 등록정보에 있는 언어만
받는다. 두 목록은 별개이므로 UI 번역 개수에 맞추려 하지 않는다.

## 어떻게 반영되나

- `build-aab.yml` 이 새 AAB 를 올릴 때, 올리는 버전 코드와 같은 이름의
  디렉터리가 있으면 **그 안의 모든 로케일을 함께 올린다.** 아무것도 더 할 필요가
  없다.
- 이미 올라간 릴리스의 노트를 고치거나 뒤늦게 채우려면 `play-release-notes.yml`
  을 쓴다. AAB 를 다시 올리지 않고 노트만 갈아 끼운다. 기본은 미리보기이고,
  `apply=true` + `confirm=<버전 코드>` 일 때만 실제로 반영된다.
